Site Popup Shield — Chrome / Edge 防弹窗与增强防护扩展

两种防护模式：

1. 🛡️ 标准模式（默认 — 无需任何权限，零弹窗提醒）：
点击“Protect this website”即刻开启，浏览器不会弹出任何安全警告或数据读取提醒！
- 拦截弹窗与外链跳转：后台监听标签页导航，阻止未经请求的新标签页、弹窗与外链跳转。
- 提升加载速度：原生 Declarative Net Request (DNR) 在网络底层阻断广告与追踪脚本，省流加速。
- 零隐私顾虑：完全不需要读取网页数据。

2. 🍪 高级页内清理（可选）：
如果想进一步清理网页内部的恼人元素，可在“Protection options”中按需勾选：
- 隐藏 Cookie 授权横幅：自动屏蔽 GDPR / Cookie 弹窗并解除页面滚动锁定。
- 拦截浮动视频与邮件弹窗：隐藏悬浮画中画视频播放器与 Newsletter 订阅弹窗。
- 仅在勾选这两项时，浏览器才会针对当前网站询问页内访问权限以执行 DOM 元素隐藏。若不勾选，保持标准零权限模式。

安装：
1. 下载并解压项目。
2. 打开 chrome://extensions 或 edge://extensions。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本文件夹。

使用：
1. 打开想保护的网站，点击扩展图标。
2. 点击 Protect this website（即刻生效，无任何权限弹窗）。
3. 点击 Reload 刷新页面。
4. （可选）展开 Protection options 开启页内清理。
